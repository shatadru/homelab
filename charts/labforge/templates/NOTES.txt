LabForge control plane {{ .Chart.AppVersion }} is installed.

This release is MODE=control with HOST_MODE=remote. Libvirt must run on a
KVM host via the labforge-agent package, not inside this pod.

1. Install labforge-agent on the hypervisor, set AGENT_TOKEN to the same value
   as Secret "{{ .Values.agent.tokenSecretName }}", and bind the agent on an
   address the cluster can reach (AGENT_BIND must not stay on 127.0.0.1).

2. AGENT_URL is {{ .Values.agent.url }}. Change it with:
   helm upgrade {{ .Release.Name }} {{ .Chart.Name }} \
     --namespace {{ .Release.Namespace }} --reuse-values \
     --set agent.url=http://kvm-host:8443

3. Guest SSH keys come from Secret "{{ .Values.sshKeys.secretName }}"
   (key "{{ .Values.sshKeys.key }}"). Create it before install if needed:

   kubectl -n {{ .Release.Namespace }} create secret generic {{ .Values.sshKeys.secretName }} \
     --from-file={{ .Values.sshKeys.key }}=$HOME/.ssh/id_ed25519.pub

{{- if not .Values.tailscale.secretName }}

4. Tailscale is disabled because tailscale.secretName is empty. To enable it,
   create a Secret and upgrade with --reuse-values:

   kubectl -n {{ .Release.Namespace }} create secret generic labforge-tailscale \
     --from-file=auth-key=/path/to/your/tailscale-auth-key
   helm upgrade {{ .Release.Name }} {{ .Chart.Name }} \
     --namespace {{ .Release.Namespace }} --reuse-values \
     --set tailscale.secretName=labforge-tailscale
{{- else }}

4. Tailscale auth key is mounted from Secret "{{ .Values.tailscale.secretName }}"
   (key "{{ .Values.tailscale.key }}"). LabForge only copies it onto the VM
   seed ISO and never reads or logs it.
{{- end }}

   open http://localhost:8899

{{- end }}
